## Tên bài Lab

- Lab 1: Bắt gói tin Telnet - SSH 


## Nội dung đã thực hiện

- Thiết lập mạng giữa Kali Linux và Windows Server 2025 trên VMware.
- Cấu hình SSH Server và kết nối SSH từ Kali vào Windows Server.
- Sử dụng Wireshark bắt và phân tích gói tin SSH.
- Thực hiện phần Telnet và so sánh với SSH.


## Kết quả thực hiện

- Kết nối SSH thành công, Wireshark bắt được các gói TCP/22 và SSHv2.
- Nội dung phiên SSH được mã hóa, không đọc được mật khẩu và lệnh trực tiếp.
- Phần Telnet đang tiếp tục thực hiện.
